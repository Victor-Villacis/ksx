Canvas behaviour

Seven states to get right, and four reasons to bother

Notes beside the working prototype. Each state is one decision, the reason it is that way, and the thing that breaks if it is not. Open Spatial Canvas to drive them.

01

Three things, never one

The world is unbounded and holds nodes in world coordinates. The camera is x, y, zoom. The viewport is whatever the browser currently shows. Nothing here ever resizes the canvas — the window resizes, the camera moves, an item resizes.

Collapse these and you get the classic bugs: dragging the window edge moves nodes, opening a panel refits the graph, undo starts swallowing pans.

02

Design-tool gestures, not map gestures

Left-drag on empty space marquee-selects; panning is two-finger, wheel, space, middle or right drag. The map model — where empty-space drag pans — is easier on first contact and worse from the second hour, once people select groups and organise sections. A visible hand tool covers anyone who does not know space-drag.

Zoom always anchors on the pointer. The world point under the cursor stays under the cursor — centre-anchored zoom forces a corrective pan every time.

04

Semantic zoom — same box, different contents

Zooming out is not shrinking. Below 50% a node is colour, icon, name and status; between 50 and 90% it adds type, ports and a one-line config summary; above 90% it adds port names, per-node controls and validation. The outer dimensions never change across a threshold, so nothing jumps, and the thresholds carry ±3% hysteresis so nothing flickers.

05

Not everything gets a resize handle

Structured nodes — API calls, branches, auth, connectors — take three width presets and let height follow content. Free drag-resize belongs to the things whose value is their size: prompt and code editors, data and response previews, notes, groups.

06

A panel opening is not a reason to refit

When the 328px inspector slides in, zoom is preserved and the camera pans by exactly the overlap needed to keep the selected node clear of it — often zero. Same on window resize: hold the zoom, hold the point being worked on. Fit workflow runs on first open of a workflow and never again on its own.

Focus mode saves the camera before it moves, dims everything but the item and its immediate neighbours, and Escape puts the view back exactly. Camera history is its own stack — panning and fitting never enter content undo.

07

Gestures are never the only way

Pinch has a single-pointer equivalent, drag-to-move has arrow keys and numeric position fields, drag-to-resize has width presets and numeric width and height. Nothing on this canvas can only be reached by a two-finger gesture, and every hit target clears 24px.

Four additions

The graph stops being a diagram

Everything above is table stakes for a canvas. These four are the reason to open this one instead of reading a log: each turns a spatial view into something you can answer a question with.

08

Lenses

O

One canvas, switchable overlays: latency, cost per run, error rate, days since edited. Each node takes a magnitude bar and its own number; the minimap tints with it, so the hot spot is findable while zoomed out. Borrowed from map layers, and the reason the minimap becomes worth looking at.

09

Straighten path

L

The graph is two-dimensional; the thing being debugged is a line. Straighten lays the trace through the selected node into one lane, hides the group boxes, holds a readable zoom rather than fitting a 3,000px lane into 600px, and Escape puts every node back where it was. Positions are restored, not approximated.
10

Payload edges

D

Edge weight becomes the tokens that crossed it — the 2,930-token hop into the model is visibly the expensive one — and hovering any edge shows the payload that actually travelled. Strokes stay screen-width, so the weighting reads at every zoom.

11

Execution replay

R

Time becomes an axis. Scrub the run and the canvas shows its state at that instant — what had finished, what was in flight, which edge was carrying. Segment widths are real durations, so the 1.84s model call visibly owns the run. Play follows the camera; touching the canvas hands control back.

Two smaller ones came along: hovering a node spotlights its whole upstream and downstream path and dims the rest, and nodes that are off-screen but connected to your selection — or failing anywhere — post a chip at the viewport edge with their distance, clickable to fly there. The panel counts as off-screen, so a node hidden behind the inspector announces itself.

The rule the rest hangs off
Zoom out to understand the system, fit a section to understand the flow, focus an item to edit it — and always return to exactly where you were.
